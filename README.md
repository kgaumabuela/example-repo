# Album Management

A Python program that models a music album collection. It defines an `Album` class and practises working with lists of objects.

## What it does

- Defines an `Album` class that stores an album's name, artist and number of songs
- Creates a list of albums and sorts it by number of songs
- Swaps two albums in the list
- Builds a second list, copies the first list into it, and adds two more albums
- Sorts the second list alphabetically by album name
- Searches the list for "Dark Side of the Moon" and prints its position

## How to run

Run `python album_management.py` in your terminal.
